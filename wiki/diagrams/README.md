# Diagram Index

Diagrams are textual Mermaid documents so they are easy to diff and update.

- `context-diagram.md`: system boundary and trust boundary.
- `data-flow.md`: pull, mutation, sync, cache, and sensitive data flows.
- `entity-relationship.md`: Notion-backed domain entities and supporting sync metadata.
- `user-flow.md`: user workflows for viewing, editing, deleting/archiving supported transactional records, and syncing.

Update diagrams when architecture, data flow, or domain relationships change.
